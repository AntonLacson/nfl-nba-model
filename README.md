## NFL/NBA Sports Analytics Model 

Sports analytics project focused on developing predictive models for NFL and NBA games. 

## Phase 1: NFL Spread Model 

The first phase of the project will develop a model that predicts NFL scoring margin: 

Home Score - Away Score 

The model's predicted margin will be compared against sportbook point spreads to evaluate predictive performance
